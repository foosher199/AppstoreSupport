Support

This support page applies to our apps that link here. Our apps focus on practical PDF document conversion for everyday work and study: convert PDF files to Word, Excel, and PowerPoint with a clear flow and easy task management.

We do not try to be an overloaded “do-everything PDF suite.” We focus on what many users need most: fast import, clear conversion status, understandable feedback, and practical file handling.

Core Features
1. Convert PDF to Word (DOCX)
2. Convert PDF to Excel (XLSX)
3. Convert PDF to PowerPoint (PPTX)
4. Add multiple files for batch conversion (where available)
5. Import via file picker; drag-and-drop may be available on some platforms
6. Track progress and task status clearly
7. Review and manage previous tasks in History
8. Save converted files locally (custom download folder on macOS; app sandbox downloads on iOS)

Why Choose Our Apps
1. Focused product direction
Designed around high-frequency conversion tasks so you can start quickly.

2. Better efficiency for repetitive work
Batch processing helps reduce repetitive steps when handling many files.

3. Clear status feedback
See whether a task is converting, completed, or failed.

4. Trackable conversion history
Past tasks are easy to review and manage for recurring workflows.

5. Practical local file handling
Keep converted files organized in a way that fits your device and platform.

Common Use Cases
1. Turn PDF reports into editable Word documents
2. Convert PDF tables to Excel for sorting and analysis
3. Convert PDF materials to PPT for presentation reuse
4. Process multiple files for class, project, or team documentation

Account and Subscription
1. Sign in with Apple is supported where cloud conversion is required
2. Plan and quota details are shown in-app
3. Restore purchases and manage subscriptions through Apple

Platform Notes
Features and UI may differ slightly between macOS and iOS. Display names may also differ across apps that share this support page. Subscription products and limits are always shown in the app you are using.
