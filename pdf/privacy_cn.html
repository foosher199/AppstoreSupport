隐私政策

引言

本隐私政策适用于所有在应用内、商店页面或相关网站中链接到本页的应用程序及服务（以下统称「本应用」）。 本应用主要提供基于云端的 PDF 文档转换等功能（例如转换为 Word、Excel、PowerPoint 等格式）， 并可能提供 macOS、iOS 或其他 Apple 平台版本。

不同应用的显示名称、图标或商店文案可能不同，但不影响本政策的适用。 使用本应用即表示您同意本隐私政策。相关条款请参阅我们的 服务条款。

我们收集的信息

账户信息（通过 Apple 登录）

若本应用提供需登录的功能（例如云端转换），您可能需要通过 Apple 登录。我们的服务可能接收并存储：

  • 您的 Apple 用户标识符
  • 我们为您的账户分配的内部账户 ID
  • 您在登录时选择分享的显示名称
  • 您在登录时选择分享的电子邮件地址（Apple 可能仅在首次登录时提供）

我们不会收到您的 Apple ID 密码。登录过程由 Apple 处理。 若您在不同设备或不同相关应用中使用同一 Apple 账号登录，可能关联到同一服务端账户。

用户内容（如 PDF 文件）

当您发起需要云端处理的任务（例如转换）时，您选择的文件会上传至我们的服务器。我们可能存储：

  • 处理进行中的原始文件
  • 处理后的输出文件，直至您下载或根据下方保留规则被删除
  • 任务元数据，例如文件名、文件大小、页数、输出格式和处理状态

我们仅将您的文件用于提供您所请求的服务。我们不会将其用于广告，也不会用于训练机器学习模型。

订阅与购买信息

若您订阅或进行应用内购买，付款由 Apple 通过 StoreKit / App Store 处理。我们不会收到您的支付卡信息。 我们可能存储提供方案权益所需的相关信息，例如：

  • 产品标识符和订阅/购买状态
  • Apple 交易标识符（例如原始交易 ID）
  • 订阅开始和到期日期
  • 您方案下的剩余使用额度或其他权益信息

各应用或平台的商品、价格与额度可能不同；具体以您所使用的应用内展示为准。

存储在您设备上的信息

本应用可能在您的设备本地存储以下数据（因平台与功能略有差异）：

  • 访问令牌 — 存储在系统钥匙串（Keychain）中，用于保持登录状态
  • 本地偏好 — 例如下载位置、界面设置等（macOS 上可能包含安全范围书签）
  • 本地缓存/下载文件 — 例如已下载的转换结果，可能保存在应用沙盒目录中，便于再次打开或分享；您可在应用内清除相关缓存

访问令牌会随 API 请求发送至我们的服务器，用于验证您的账户。 其他本地偏好与已下载文件默认不会作为「同步数据」上传（您主动选择上传处理的文件除外）。

我们不收集的信息

我们不会收集：

  • 位置数据
  • 通讯录、日历或照片（除您主动选择用于处理的文件外）
  • 本应用以外的浏览历史
  • 广告标识符或跨应用追踪数据
  • 通过第三方分析 SDK 收集的分析数据

我们如何使用信息

我们将上述信息用于：

  • 创建和管理您的账户
  • 验证对我们 API 的请求
  • 处理您提交的文件并交付结果
  • 应用本应用中显示的方案限制（例如文件大小、页数和使用额度）
  • 在本应用中显示历史记录（如适用）
  • 验证 App Store 订阅/购买并恢复购买
  • 响应支持请求并处理服务滥用行为

存储、保留与删除

数据存储位置

上传的文件和处理结果存储在云对象存储中。账户、订阅和任务记录存储在我们的数据库中。 这些系统由我们用于运行服务的第三方托管提供商运营。

数据保留期限

  • 上传和处理后的文件通常会在任务创建后约 24 小时 内从云存储中删除， 若您删除任务或账户，则会更快删除。
  • 文件删除后，任务历史记录可能仍会保留，以便本应用显示过往记录（包括下载已不可用的情况）。
  • 账户和订阅记录在您的账户处于活跃状态期间保留。

删除您的账户

若本应用提供账户功能，您通常可在应用的账号或设置中通过删除账号功能删除账户。这将永久删除：

  • 您在我们服务器上的个人资料和登录记录
  • 与您账户关联的订阅/权益记录（服务端记录）
  • 历史记录和使用额度记录
  • 仍为您账户存储的相关文件

删除账户不会取消 App Store 订阅。请在 Apple ID 账户设置中取消订阅。

退出登录或删除账户会清除本应用中的会话。本地钥匙串数据及平台相关本地偏好/缓存也可能被清除； 卸载本应用会删除该设备上的本地应用数据。

信息共享

我们不会出售您的个人信息。我们仅在以下情况下共享信息：

  • Apple — 通过 Apple 登录和 App Store 订阅/购买处理， 受 Apple 隐私政策 约束。
  • 服务提供商 — 帮助我们运营本应用和处理任务的托管、数据库和文件存储提供商。
  • 法律要求 — 在法律要求时，或为保护用户、我们的服务或公众时。

追踪

我们不会在其他公司拥有的应用或网站中追踪您，也不会在本应用中展示定向广告。

安全

本应用与我们服务器之间的通信使用 HTTPS/TLS。访问令牌（如有）存储在系统钥匙串中。 任何在线服务都无法保证绝对安全。

儿童隐私

本应用不面向 13 岁以下儿童。若您认为儿童向我们提供了个人信息，请联系我们，我们将予以删除。

国际用户

您的信息可能在您所在国家/地区以外的服务器上处理。使用本应用即表示您理解， 您的信息可能被传输至并在这些地点处理。

政策变更

我们可能不时更新本隐私政策。更新时，本页顶部的「最后更新」日期会相应变更。 更新后继续使用本应用，即表示您接受修订后的政策。
